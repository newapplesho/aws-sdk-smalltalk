# S3

See [Usage](../usage.md) for credential options, session tokens, and error
handling.

```smalltalk
AWSS3Config default
    accessKeyId: 'AWS_ACCESS_KEY_ID';
    secretKey: 'AWS_SECRET_ACCESS_KEY';
    regionName: 'ap-northeast-1'.

s3 := AWSS3 new.

"Buckets"
s3 createBucket: 'st-test1'.
s3 listBuckets.                         "an OrderedCollection of S3Bucket"
s3 deleteBucket: 'st-test1'.

"Objects"
bucket := s3 bucketNamed: 'st-test1'.
bucket atKey: 'sample.txt' putObject: 'hello world'.
bucket getObject: 'sample.txt'.
bucket listObjects.
bucket deleteObject: 'sample.txt'.
```

Note: an `S3Bucket` obtained from `bucketNamed:` uses `AWSS3Config default`. If
you configured the service through `profile:` or `awsConfig:` instead, point
the bucket at it: `(s3 bucketNamed: 'st-test1') service: s3`.
